# Villa Emilia

Landing page bilingüe de Villa Emilia con galería, información de la propiedad y formulario de reservas por WhatsApp.

## Uso local

Abre `index.html` en un navegador. No requiere instalación ni proceso de compilación.

## Publicación

El sitio es compatible con GitHub Pages porque todos los recursos son estáticos y usan rutas relativas.
